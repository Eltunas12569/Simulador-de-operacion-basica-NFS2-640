# Simulador de Panel de Control NFS2-640

Este repositorio contiene un simulador web interactivo diseñado para la capacitación en la operación básica del panel de control contra incendios **NFS2-640**.

## Propósito
El proyecto tiene como objetivo servir como una **herramienta educativa** para facilitar el aprendizaje de los protocolos y funciones esenciales del panel de control mencionado.

> **Nota:** Este proyecto ha sido desarrollado exclusivamente con fines académicos y de divulgación. No tiene fines de lucro y no está afiliado ni avalado por el fabricante del equipo original.

## Tecnologías Utilizadas
* HTML5
* CSS3
* JavaScript (Vanilla)

## Instrucciones de Uso
1.  Clona este repositorio o descarga el archivo `.zip`.
2.  Abre el archivo `index.html` en tu navegador web de preferencia (Chrome, Firefox, Edge, etc.).
3.  Interactúa con la interfaz para explorar las funciones de operación básica.
